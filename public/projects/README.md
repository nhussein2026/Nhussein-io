# Project screenshots

Drop a screenshot here for each project and it appears automatically on the
Projects section — no code changes needed. Until a file exists, a branded
placeholder is shown instead.

Expected filenames (must match exactly):

| Project | File |
|---------|------|
| 3skici  | `3skici.png` |
| Ghiras  | `ghiras.png` |
| Safha   | `safha.png`  |
| Isnnad  | `isnnad.png` |
| DevLab  | `devlab.png` |

Tips for good screenshots:

- Use a **16:9** crop (e.g. 1280×720) — cards are sized for that ratio.
- Capture the most visual/impressive screen of the app, not a login page.
- Keep files reasonably small (compress PNGs, or use `.jpg` and update the
  `img` filename in `src/components/projects/Projects.js`).
- A short screen-recording turned into a GIF also works well for demos
  (especially for 3skici, which has no public live demo).

## The problem

Most programming tutorials are written in English. Safha publishes tutorials and articles for developers who read Arabic first.

## My part

Safha is my own developer blog. I started it on WordPress with a custom theme, then moved it to Astro, which it runs on today.

## Key decisions

- **Reading first, right to left** The layout is built for Arabic technical text, with code blocks that stay left to right.
- **Code you can run** Tutorials include code-display sections and a live example editor.

## The result

Safha is live at safha.dev.

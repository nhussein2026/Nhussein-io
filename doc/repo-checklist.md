# Repository checklist

Every public repository under `nhussein2026`, reviewed one at a time. When a repository is done, tick it and strike it through:

```markdown
- [x] ~~**DevLab**~~ · 2024-01 · done 19 Nov 2026
```

Private repositories are tracked in `doc/private/repo-checklist-private.md`, which is never committed, because their names are not public.

**Done means:**
1. **Safe:** full history checked for secrets, `.env` files, real data and the old email.
2. **Verdict:** keep, archive, make private or delete.
3. **README:** kept repositories follow the [README Standard v1.1](readme-standard.md).
4. **GitHub settings:** description, website and one category topic.

**On the site:** Journey lists only reviewed repositories (the `SHOWN` list in `scripts/fetch-repos.mjs`). The portfolio launches with the reviewed ones; each repository joins the list when its review is done, so the launch does not wait for all 43. Repositories marked *on site* are on the list.

**Progress:** 4 of 43 done (34 own, 9 forks) · 3 on the site (DevLab, career-copilot, Rafiq-ai).
